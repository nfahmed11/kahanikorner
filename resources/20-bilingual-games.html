A Sneak Peek

Game 1

The Wrong Word Game

During breakfast, deliberately name an object incorrectly.

“Can you pass me the joota?” — while pointing to the spoon. The child corrects the parent: “No, that is a chamach!”

Game 2

Secret Language Mission

Choose one word for the child to use naturally three times during the day.

Example word: paani

Game 3

Laundry Sorting Detective

Ask the child to find clothes using bilingual clues.

“Find something neela.”
“Whose qameez is this?”
